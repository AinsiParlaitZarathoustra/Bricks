# Graph Memory Benchmarks

Measurements of the graph store (Grafeo, the `graph` feature of `bricks-memory`) and of the file-based memory, from the benchmark report of **8 October 2026** (`docs/benchmarks-bricks-2026-10-08.md` in the repository). Bricks 0.4.6 at commit `dee981e`, Apple A18 Pro, macOS 27.2, release build. Each figure is a mean over warm runs, on temporary files.

<Callout type="warn">
These figures were taken before the change that runs each `Bash` call in its own process (commit `4263cd9`). They do not involve `Bash`, but they describe the code at `dee981e`. Run the benchmark again before you rely on a figure.
</Callout>

## Local memory

| Operation | Mean | Min | Max |
|-----------|-----:|----:|----:|
| Scan of 100 files with frontmatter | 1.84 ms | 1.46 ms | 3.69 ms |
| Load `MEMORY.md` | 15.4 µs | 12.9 µs | 118.9 µs |
| Text recall over 100 files | 2.03 ms | 1.58 ms | 4.20 ms |
| Graph write, 1,000 nodes | 76.2 µs per node | – | – |
| Graph recall, 1,000 nodes | 1.36 ms | 1.18 ms | 4.99 ms |
| Query by subject | 114.5 µs | 104.6 µs | 145.3 µs |
| Session write | 35.9 µs per entry | 25.5 µs | 383.7 µs |
| Session load, 100 entries | 279.3 µs | 237.7 µs | 381.5 µs |

These are local file and graph measurements. They are not a memory-quality benchmark: for that, see [LongMemEval](/docs/bench-memory).

## Graph at 10,000 nodes

The report ran 10 workers with 100 queries each, so 1,000 samples, against a graph of 10,000 nodes:

| Mean | p50 | p95 | p99 |
|-----:|----:|----:|----:|
| 87.99 ms | 83.03 ms | 130.01 ms | 226.49 ms |

The report notes that the binary's banner still announced 100 agents, while the code ran 10 workers. The 100,000-node step was not run, and its zero fields in the JSON output are not measurements.

## Reproduce on current code

The old `memory_bench.rs` example and standalone `GraphMemory` API have been removed. `bricks-memory` now provides structured memory (`crates/bricks-memory/src/structured/`), which stores episodes, entities, and facts in Grafeo alongside a `usearch` vector index.

To measure structured memory latency on a synthetic corpus from the repository root:

```bash
cargo run --release -p bricks-memory --features structured --example measure_memory
```

The example lives at `crates/bricks-memory/examples/measure_memory.rs` and reports ingestion time per episode, reopen time, and recall p50/p95 over 200 queries.
