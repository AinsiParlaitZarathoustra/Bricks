# Cookbook: Structured Graph Memory

`bricks-memory` stores long-term memory in `StructuredMemory` (`crates/bricks-memory/src/structured/`). It uses Grafeo as an embedded graph database (`:Episode`, `:Entity`, `:Alias`, `:Fact`, `:MemoryMeta` nodes) alongside a `usearch` vector index and Grafeo full-text search.

<Callout type="info">
The older `GraphMemory`, `MemoryManager`, and `memdir` modules were removed. Structured memory (`bricks-memory` with the `structured` feature) is the current graph-backed memory system.
</Callout>

Add `bricks-memory` with the `structured` feature (and `bricks-embeddings`) to your `Cargo.toml`:

```toml
bricks-memory = { version = "1.0.0-alpha.1", features = ["structured"] }
bricks-embeddings = "1.0.0-alpha.1"
tokio-util = "0.7"
```

## Opening a store

`StructuredMemory::builder` takes an `Arc<dyn EmbeddingProvider>`. Use `HashingEmbeddings` for local tests or offline use, or `OpenAiEmbeddings` / `GeminiEmbeddings` for semantic search.

```rust
use bricks_embeddings::HashingEmbeddings;
use bricks_memory::structured::StructuredMemory;
use std::sync::Arc;

let embedder = Arc::new(HashingEmbeddings::new(384));

// File-backed store (or omit .path(...) for in-memory)
let memory = StructuredMemory::builder(embedder)
    .path("./memory.db")
    .open()?;
```

If you also want automatic fact and entity extraction from episodes, pass an `Extractor` (such as `LlmExtractor`) via `.extractor(...)`. Without an extractor, episodes are stored and embedded for vector and lexical recall without creating `:Fact` nodes.

## Recording episodes

Use `record` with an `EpisodeInput`. Each episode belongs to a space (such as `GLOBAL_SPACE` or `project_space("my-project")`).

```rust
use bricks_memory::structured::{EpisodeInput, GLOBAL_SPACE};
use tokio_util::sync::CancellationToken;

memory
    .record(EpisodeInput {
        space: GLOBAL_SPACE.into(),
        project_id: Some("my-project".into()),
        session_id: Some("session-1".into()),
        role: "user".into(),
        author: None,
        content: "Authentication uses JWT with RS256 stored in HttpOnly cookies.".into(),
        occurred_at: None,
        source_ref: None,
    })
    .await?;

// Run extraction (if configured) and compute pending embeddings
let report = memory.process(&CancellationToken::new()).await?;
println!("embedded: {}, facts created: {}", report.embedded, report.facts_created);
```

## Recalling memories

`recall` runs three-way Reciprocal Rank Fusion (RRF) across vector similarity, lexical BM25, and graph expansion over entities, filtered by space and temporal validity.

```rust
use bricks_memory::structured::RecallQuery;

let result = memory
    .recall(&RecallQuery::new("How does authentication work?"))
    .await?;

for item in result.items {
    if let Some(fact) = item.fact {
        println!("[fact {:.3}] {}", item.score, fact.statement);
    } else if let Some(ep) = item.episode {
        println!("[episode {:.3}] {}", item.score, ep.content);
    }
}
```

## Retracting and forgetting

You can retract a single fact or forget all episodes from a session:

```rust
memory.retract(&fact_id).await?;
memory.forget_session("session-1").await?;
```

## Using it with an agent

`bricks` attaches structured memory to an agent through `Agent::builder().long_term_memory(...)` using `ScopedMemory::for_run(...)`, which scopes writes to the project space and recalls from both the project and global spaces.

For full details on spaces, extraction, and desktop/CLI configuration (`[memory]` in `bricks.toml`), see [Memory API](/docs/api-memory).
